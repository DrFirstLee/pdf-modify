개인정보처리방침

PDF Master는 아무 개인정보도 저장하지 않습니다. PDF 파일, 파일 이름, 작업 내용, 선택 영역, 페이지 정보도 서버에 업로드하거나 저장하지 않습니다.

아무 개인정보도 저장하지 않습니다

사용자가 선택한 PDF는 브라우저 안에서만 처리됩니다. 페이지를 닫거나 새로고침하면 선택한 파일과 작업 상태는 사라집니다.

저장하지 않는 정보

PDF 파일, 문서 내용, 파일 이름, 페이지 선택, 크롭 영역, 병합 순서 등 사용자가 작업한 정보를 PDF Master는 저장하지 않습니다.

업로드하지 않는 처리 방식

PDF 분할, 병합, 순서 변경, 크롭 작업은 사용자의 브라우저 메모리에서 실행됩니다. 별도의 파일 업로드 서버를 사용하지 않습니다.

브라우저 세션

작업 중 표시되는 미리보기와 선택 상태는 현재 페이지에서만 유지됩니다. 페이지를 닫거나 새로고침하면 초기화됩니다.

외부 서비스

사이트 운영을 위해 정적 호스팅, 검색 등록, 광고 서비스가 사용될 수 있습니다. 다만 PDF Master 자체는 사용자의 PDF 파일을 수집하거나 보관하지 않습니다.
