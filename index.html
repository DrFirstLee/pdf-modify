원하는 작업 선택

작업을 고르고 다운로드 버튼을 누르면 새 PDF가 생성됩니다.

여러 PDF를 하나로 병합

왼쪽 파일 목록의 순서대로 모든 페이지를 합칩니다. 화살표 버튼으로 순서를 바꿀 수 있습니다.

필요한 페이지만 추출

예: 1-3, 5, 8-10. 첫 번째 PDF에서 지정한 페이지만 새 PDF로 만듭니다.

PDF 내부 페이지 순서 변경

첫 번째 PDF의 페이지를 원하는 순서로 입력하세요. 예: 3, 1, 2, 4-6.

페이지 가장자리 크롭

첫 번째 PDF에서 선택한 페이지의 위, 오른쪽, 아래, 왼쪽 여백을 포인트 단위로 잘라냅니다. 72pt는 약 1인치입니다.

파일은 저장되지 않습니다

PDF Master는 선택한 파일을 서버에 업로드하지 않고, 브라우저에서만 처리합니다.

처리 후 흔적 최소화

페이지를 새로고침하거나 닫으면 선택한 파일 목록과 작업 상태가 사라집니다.

명확한 사용 안내

광고 게재 정책에 맞게 기능, 제한, 개인정보 처리 방식을 사용자에게 분명히 안내합니다.

PDF Master 사용 방법

PDF 병합

여러 파일을 추가한 뒤 파일 목록의 위아래 버튼으로 순서를 정하고 병합 다운로드를 누릅니다.

PDF 분할

첫 번째 PDF를 기준으로 필요한 페이지 범위를 입력하면 해당 페이지만 새 파일로 저장됩니다.

순서 변경

페이지 번호를 원하는 순서대로 입력하면 내부 페이지 순서가 바뀐 PDF를 받을 수 있습니다.

크롭

잘라낼 여백 값을 포인트 단위로 입력합니다. 원본 파일은 수정되지 않고 새 파일만 생성됩니다.
