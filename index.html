여러 PDF를 하나로 병합

왼쪽 파일 목록의 순서대로 모든 페이지를 합칩니다. 화살표 버튼으로 순서를 바꿀 수 있습니다.

필요한 페이지만 추출

아래 미리보기에서 필요한 페이지를 클릭하세요. 직접 입력하려면 예: 1-3, 5, 8-10 형식도 사용할 수 있습니다.

PDF 내부 페이지 순서 변경

아래 미리보기에서 페이지를 드래그해 원하는 순서로 바꾸세요. 여러 PDF를 올려도 모든 페이지를 한 번에 재정렬할 수 있습니다.

마우스로 영역 선택

아래 미리보기에서 크롭할 페이지 위를 마우스로 드래그하세요. 선택한 사각형 영역만 새 PDF로 저장됩니다.

PDF를 Word 또는 PPT로 저장

첫 번째 PDF를 Word 문서 또는 PPT 프레젠테이션으로 내보냅니다. Word는 텍스트 중심, PPT는 각 페이지를 슬라이드 이미지로 저장합니다.

페이지 미리보기

첫 번째 PDF의 페이지를 확인하고, 분할할 페이지를 클릭하거나 크롭 탭에서 드래그하세요.

PDF를 추가하면 페이지가 여기에 표시됩니다.

파일은 저장되지 않습니다

PDF Master는 선택한 파일을 서버에 업로드하지 않고, 브라우저에서만 처리합니다.

처리 후 흔적 최소화

페이지를 새로고침하거나 닫으면 선택한 파일 목록과 작업 상태가 사라집니다.

Word/PPT도 로컬 변환

.docx와 .pptx는 브라우저에서 PDF로 변환한 뒤 같은 도구로 작업합니다. 오래된 .doc/.ppt는 먼저 최신 형식으로 저장해 주세요.

PDF Master 사용 방법

PDF 병합

여러 파일을 추가한 뒤 파일 목록의 위아래 버튼으로 순서를 정하고 병합 다운로드를 누릅니다.

PDF 분할

첫 번째 PDF를 기준으로 필요한 페이지 범위를 입력하면 해당 페이지만 새 파일로 저장됩니다.

순서 변경

미리보기에서 페이지를 드래그하면 여러 PDF의 페이지도 한 번에 원하는 순서로 재정렬할 수 있습니다.
